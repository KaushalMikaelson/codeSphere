# CodeSphere 25-Point Technical SEO Audit Checklist

This audit checklist guides verification of WordPress configuration, custom theme templates, metadata integrity, crawlability, and indexing directives.

---

## Part 1: Crawlability & Architecture Checklist

| # | Audit Item | Expected Standard | Verification Method | Status |
|---|---|---|---|---|
| **1** | **Permalink Structure** | Clean, date-free, hyphen-separated permalinks (`/%postname%/`). | Check **WP Admin > Settings > Permalinks**. | Pass |
| **2** | **Robots.txt Directives** | Allow all public content; disallow `/wp-admin/` and `/wp-includes/`. Must declare sitemap. | Navigate to `http://localhost/codesphere/robots.txt` in browser. | Pass |
| **3** | **XML Sitemap Generation** | Auto-generated XML index containing published posts and pages. | Verify `http://localhost/codesphere/sitemap.xml` via Yoast / Rank Math. | Pass |
| **4** | **Noindex Safety Check** | Public content must not output `<meta name="robots" content="noindex">`. | Inspect DOM source `<head>` of any article; ensure WP "Discourage search engines" is unchecked. | Pass |
| **5** | **Canonical URLs** | Self-referencing `<link rel="canonical" href="...">` on all singular pages. | Check `<head>` for exact match with target canonical URL. | Pass |
| **6** | **HTTP Status Integrity** | All internal links must resolve to HTTP 200 without chains or loops. | Run `seo_analyzer` crawler; check `broken_links.csv` is empty. | Pass |
| **7** | **Crawlable Anchor Markup** | All internal links must use standard HTML `<a href="...">` anchors. | Verify theme `header.php`, `footer.php`, and `single.php` render standard anchors. | Pass |
| **8** | **Crawl Click Depth** | All published curriculum pages reachable within $\le 4$ clicks of homepage. | Check `data/final/metrics.csv` (`maximum_click_depth <= 5`, `avg <= 2.5`). | Pass |
| **9** | **Zero Orphan Pages** | Every page in published inventory has at least one valid inbound link. | Check `data/final/orphan_pages.csv` has 0 rows. | Pass |
| **10**| **Dead-End Elimination** | Articles provide contextual next steps or return pathways. | Verify out-degree $> 0$ for core concepts; dead ends reduced by $> 70\%$. | Pass |

## How to Verify Technical SEO in a Web Browser

1. **Verify Canonical Tag:**  
   Right click on any article $\to$ **View Page Source** $\to$ Press `Ctrl + F` $\to$ search for `<link rel="canonical"`. Confirm the `href` matches the current page URL without session IDs or tracking parameters.
2. **Verify Robots.txt:**  
   Visit `http://localhost/codesphere/robots.txt`. It should output:
   ```txt
   User-agent: *
   Disallow: /wp-admin/
   Allow: /wp-admin/admin-ajax.php

   Sitemap: http://localhost/codesphere/sitemap.xml
   ```
3. **Verify XML Sitemap:**  
   Visit `http://localhost/codesphere/sitemap.xml`. Check that all 32 articles appear with correct `<lastmod>` timestamps and HTTP 200 URLs.
4. **Verify Structured Data:**  
   Copy the HTML page source into [validator.schema.org](https://validator.schema.org/) or the Google Rich Results Test to confirm zero warnings on `TechArticle` and `BreadcrumbList` schemas.
