# Competitor SEO & Content Analysis Framework

This template provides an academic, reproducible auditing framework for evaluating competing computer science educational platforms (e.g., GeeksforGeeks, Programiz, W3Schools, freeCodeCamp, LeetCode Explore).

> **Academic Integrity Notice:**  
> In compliance with strict research ethics, this framework does not include fabricated search volumes, estimated organic traffic, domain authority scores, or scraped ranking positions. All empirical metrics must be captured through official APIs or verified research accounts (e.g., Google Search Console, Google Keyword Planner) and marked with timestamps and collection methodologies.

## 2. Standard Operating Procedure (SOP) for Real Data Collection

To gather genuine organic keyword metrics and competitive intelligence without scraping search engines in violation of terms of service:

### Step 1: Google Keyword Planner (Search Volume & Competition)
1. Sign in to an active Google Ads account and navigate to **Tools and Settings > Keyword Planner**.
2. Select **Discover new keywords** and enter the primary target seeds:
   - `data structures in programming`
   - `binary search tree`
   - `recursion explained with examples`
   - `difference between SQL and NoSQL`
3. Set the target location to **India** and language to **English**.
4. Export the official CSV containing:
   - *Average monthly searches*
   - *Three-month change*
   - *Year-over-year change*
   - *Competition index (Low, Medium, High)*
5. Place the exported data in `docs/seo/raw/gkp-india-export-YYYY-MM.csv` and cross-reference with `docs/seo/keyword-page-map.csv`.

### Step 2: Google Search Console (GSC) Impressions & Click-Through
1. Once CodeSphere is deployed with a verified custom domain, verify ownership via DNS TXT record in Google Search Console.
2. Submit the XML sitemap generated by Yoast SEO or Rank Math (`https://codesphere.edu/sitemap.xml`).
3. Monitor the **Performance Report** after 14 days of indexation to record:
   - *Real search impressions*
   - *Actual user clicks*
   - *Average CTR*
   - *Average organic SERP position*
4. Compare pages with in-degree $> 2$ vs in-degree $\le 1$ to test if crawl discovery correlates with indexation velocity.
